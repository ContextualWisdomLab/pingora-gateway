# Pingora Gateway

Pingora Gateway is the shared edge-runtime boundary for ContextualWisdomLab-managed reverse-proxy traffic.

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/ContextualWisdomLab/pingora-gateway)

## Current status

Protected `main` is currently a repository scaffold. There is no published GitHub release or production runtime on that branch yet. The repository is intended to host a Rust edge runtime built on Cloudflare Pingora and to expose versioned edge configuration or contracts so consuming products do not bind directly to Pingora implementation types.
