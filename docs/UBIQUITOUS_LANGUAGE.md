# Ubiquitous Language

**Gateway** — reusable CWL edge process implemented on Pingora. **Route** — aggregate member pairing a downstream matcher with one validated static upstream. **Route ID** — stable operator-facing identifier, safe for low-cardinality telemetry. **Route Table** — aggregate enforcing uniqueness and deterministic precedence. **Upstream Target** — resolved origin socket plus HTTP/HTTPS hostname/authority semantics. **Private-network opt-in** — explicit configuration decision allowing an origin to resolve to non-public address space. **Delivery adapter** — Pingora-specific Anti-Corruption Layer that maps HTTP transport state to domain routing decisions. **Consumer** — a product repository/deployment that uses the shared runtime while retaining its own domain policy. **Migration evidence** — RED characterization plus GREEN production-path proof for the behavior actually replaced.
