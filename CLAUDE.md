# Repository Working Notes

Use `AGENTS.md` as the engineering contract. The central design rule is that admitted edge contracts own domain invariants while Pingora remains a delivery adapter. `edge_routing` and `http_policy` may contain executable consumer-derived characterization only when the responsibility is genuinely shared edge behavior; they do not own product authorization, business routing, domain response semantics, Wardnet/EgressWeave verdicts, or Keyverse identity.

Before a material change, compare the proposed module/path/API/config name with `PRD.md`, `TRD.md`, `ARCHITECTURE.md`, `CONTEXT_MAP.md`, and `UBIQUITOUS_LANGUAGE.md`. After the change, update tests and the gap baseline. Do not claim release, migration, performance, SBOM/provenance, graceful-drain verification, or image digest evidence unless the exact protected revision proves it.

The generic v1 runtime intentionally supports one upstream per process. The stacked pg-erd migration candidate is a separate versioned composition root: its fixed characterized route table and response-security policy can be activated only by `cwl-pingora-pg-erd-migration` from bounded `PgErdMigrationConfig` with explicit `backend` and `frontend` transport authority. That candidate is not a protected release or consumer cutover. Widening the generic runtime to multiple upstreams, adding arbitrary route-table or response-policy configuration, load balancing, WebSocket behavior, downstream TLS, static serving, dynamic reload, or Kubernetes Gateway API remains a versioned product increment rather than an opportunistic helper.

Downstream TLS/HTTP/2 is specifically governed by `pingora-gateway#51` and Proposed ADR 0012. The current composition roots remain clear-text `add_tcp` listeners and current upstream peers remain `ALPN::H1`; do not add a TLS listener or enable H2 piecemeal without the versioned listener contract, consumer old-edge characterization, and exact-supplier H2-to-H1 translation RED/GREEN. Do not switch upstream ALPN, enable h2c, pin a mutable supplier PR, or retain a legacy front proxy merely to manufacture H2 parity. HTTP/3/QUIC stays fail-closed until a separately accepted immutable transport capability and executable evidence exist.
